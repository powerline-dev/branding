# Typography

Powerline Dev uses bold monospace typography inspired by terminals and developer tools.

## Font Family

The standard font stack used across official brand assets:

```css
font-family:
  ui-monospace,
  SFMono-Regular,
  Menlo,
  Consolas,
  monospace;
```

## Font Weight

| Element | Weight |
|---|---|
| Organization wordmark | `700` |
| Project wordmarks | `700` |
| Brand headings | `700` |
| Supporting text | `400` |

## SVG Typography

Official SVG wordmarks use the following typography settings:

```xml
<text
  font-family="ui-monospace, SFMono-Regular, Menlo, Consolas, monospace"
  font-weight="700"
  font-size="64"
>
  Powerline Dev
</text>
```

The font size may be adjusted depending on the asset dimensions.

The actual font face may vary by operating system and available system fonts. For pixel-consistent assets, use outlined SVG text or raster exports generated from an approved font.

## Capitalization

Use the following naming conventions:

| Context | Format |
|---|---|
| Organization name | `Powerline Dev` |
| GitHub organization | `powerline-dev` |
| Project display name | `Codex Powerline CLI` |
| Repository name | `codex-powerline-cli` |

## Usage Guidelines

- Use bold monospace typography for official wordmarks.
- Preserve the original capitalization.
- Maintain balanced character spacing.
- Avoid decorative or script fonts.
- Avoid shadows, outlines, and unnecessary text effects.
- Apply the signature color palette to official wordmarks.

These guidelines apply to brand assets, not necessarily to application interfaces or documentation body text.
